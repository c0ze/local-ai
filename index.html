WebGPU is not available in this browser

This app runs AI models locally via WebGPU. Without it, model inference won't work.

  • Chrome / Edge 113+: enabled by default; otherwise your GPU may be blocklisted.
  • Safari 17.4+: requires macOS Sonoma.
  • Firefox: Nightly only, with dom.webgpu.enabled in about:config.
  • Linux / AMD: in chrome://flags, enable Unsafe WebGPU and Vulkan, then relaunch.
  • White video after Vulkan? Try Choose ANGLE graphics backend → OpenGL, then Zero-copy rasterizer → Disabled. If video is still white, disable only Hardware-accelerated video decode.

WebGPU setup

Chrome / Edge

  1. Open chrome://flags.
  2. Enable Unsafe WebGPU.
  3. Relaunch the browser.

Linux / AMD

  1. Open chrome://flags.
  2. Enable Vulkan.
  3. Open chrome://gpu and confirm WebGPU is hardware accelerated.
  4. In this app, Settings → Hardware should show the real GPU, not google · swiftshader.

White video after Vulkan

  1. In chrome://flags, set Choose ANGLE graphics backend to OpenGL.
  2. If video is still white, set Zero-copy rasterizer to Disabled.
  3. If needed, disable only Hardware-accelerated video decode.

Keep Chrome Settings → System → Use graphics acceleration when available turned on.

Chrome may block direct chrome:// links from web pages. If a link does not open, copy it into the address bar.
